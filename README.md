# coding.kitty agent skills

Agent skills from [coding.kitty](https://thecodingkitty.com), in the open
[Agent Skills](https://agentskills.io) format. They work with Claude Code, Codex,
Cursor, GitHub Copilot, Gemini CLI and any other agent that reads `SKILL.md`.

## Install

```bash
# Pick from the list
npx skills add codingkitty7/agent-skills

# Or install one by name
npx skills add codingkitty7/agent-skills --skill <name>
```

Each skill's page has install steps for every agent, a download, and the full
`SKILL.md` to read before you install.

## About this repo

This repo is generated. The skills are written and reviewed alongside their
pages on thecodingkitty.com, then copied here automatically, so a change made
directly in this repo is overwritten by the next sync. Found a problem? Open an
issue here.

Every skill is checked against the same safety list we use for community skills:
no network calls unless the skill needs them, no obfuscated scripts, no
instructions to hide what the agent does, and no secrets.
See [how we check a skill is safe](https://thecodingkitty.com/blog/check-agent-skill-mcp-server-safety).
